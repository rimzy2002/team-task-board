### M3 — Owner-scoped Task API
- Scope: `GET /api/projects/{id}/tasks` returns 200, `POST /api/projects/{id}/tasks` returns 201, `PUT /api/tasks/{id}` returns 200, and `DELETE /api/tasks/{id}` returns 204. Every endpoint requires Firebase JWT authentication. Missing and foreign resources both return 404. Request bodies reject unknown fields, including IDs, owner fields, and Firebase UIDs.
- Request fields: `title` (required, trimmed, up to 200 characters), `description` (optional, up to 65,535 UTF-8 bytes after trimming), `status` (`ToDo`, `InProgress`, `Done`), `priority` (`Low`, `Medium`, `High`), `dueDate` (optional calendar date as `YYYY-MM-DD`), and `assignee` (optional trimmed free text, up to 200 characters). POST defaults omitted or null status and priority to `ToDo` and `Medium`. PUT is a full replacement and requires status and priority. Blank optional text becomes null, and omitted optional PUT fields clear the existing values.
- Due dates and timestamps: A new or changed non-null due date must be today or later in UTC. An existing overdue date can be kept unchanged when other fields are updated, including status. Creation and update timestamps come from the server. PUT preserves the original creation timestamp.
- M4 API contract: `GET /api/projects/{id}/tasks?status=ToDo&priority=High&search=invoice&page=1` accepts any combination of filters. Search is a trimmed, literal title substring up to 200 characters using the database collation. Pages start at 1 and have a fixed size of 10. Results are ordered by descending task ID. GET returns `{ items, page, pageSize, totalCount }`. The total counts tasks after filtering, and pages beyond the last return `items: []` with the total. Task DTO fields are `id`, `projectId`, `title`, `description`, `status`, `priority`, `dueDate`, `assignee`, `createdAtUtc`, and `updatedAtUtc`.
